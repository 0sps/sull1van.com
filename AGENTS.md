## Sean's UI Preferences

- Never use movement effects on button hover states. Buttons should not translate, lift, slide, scale, bounce, or otherwise move when hovered. Color, border, brightness, shadow, and opacity changes are fine, but hover movement on buttons is a design anti-pattern for Sean.

## Shell Preferences

- Whenever running terminal commands, ALWAYS use Homebrew zsh at `/opt/homebrew/bin/zsh`, not the stock macOS shell at `/bin/zsh`.

## Testing Preferences

- Never launch a browser or simulator, or install any software for testing, without first asking Sean for explicit permission and receiving that permission in the conversation.

## Sean's Writing Preferences

- Avoid stock AI-writing pivots like "it's not X, it's Y" unless someone actually framed the topic as X and the contrast is necessary.
- Do not use em dashes in Sean's writing. Use commas, periods, colons, or parentheses instead.
- Avoid canned dramatic phrases like "and for the first time, BLANK."
- Avoid staccato hype patterns and fake profundity, including constructions like "X is why. Read that again."
- Avoid synthetic urgency phrases like "no one is talking about this" or "X is silently killing the industry."
- Preserve Sean's direct, conversational voice. Tighten grammar and structure without adding glossy essay-closing theatrics, LinkedIn cadence, or generic AI-blog rhetoric.

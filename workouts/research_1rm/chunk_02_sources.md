# Chunk 02 research: ex038-ex074

## Formula selected

For externally loaded movements with a meaningful estimated 1RM, this chunk uses the Epley equation:

`w*(1+(r/30))`

Here, `w` is the external weight used and `r` is completed repetitions. The equation and its intended use to estimate 1RM from a submaximal weight-and-repetition set are documented by the [Epley calculator and source note](https://www.thestandardengine.com/health/epley-one-rep-max-calculator). A second calculator describes it as an estimate for [any lift](https://megacalc.org/calculators/one-rep-max). Estimates are most defensible for low-repetition, near-failure sets, and machine results are comparable only on the same machine setup.

## Named-lift and family evidence

The following pages explicitly report load-based one-rep-max standards for the named lift or a clearly corresponding exercise family. Combined with the Epley source above, they support using the formula for the listed IDs.

- Rows and pulldowns, ex038, ex041, ex042, ex045, ex051, ex061, ex062, ex063, ex071: [Seated Cable Row](https://strengthlevel.com/strength-standards/seated-cable-row), [Lat Pulldown](https://strengthlevel.com/strength-standards/lat-pulldown/kg), [Bent Over Row](https://strengthlevel.com/strength-standards/bent-over-row/kg), [T-Bar Row](https://strengthlevel.com/strength-standards/t-bar-row/kg). MTS entries were mapped to their selectorized row or pulldown family.
- Hip thrusts, split squats, and loaded lunges, ex039, ex040, ex054: [Hip Thrust](https://strengthlevel.com/strength-standards/hip-thrust), [Bulgarian Split Squat](https://strengthlevel.com/strength-standards/bulgarian-split-squat/kg), [Dumbbell Lunge](https://strengthlevel.com/strength-standards/dumbbell-lunge). The Booty Builder entry is a selectorized hip-thrust machine, so only same-machine comparisons are appropriate.
- Raises, face pulls, and shoulder presses, ex043, ex046, ex052, ex058, ex060, ex066, ex067: [Dumbbell Lateral Raise](https://strengthlevel.com/strength-standards/dumbbell-lateral-raise/lb), [Face Pull](https://strengthlevel.com/strength-standards/face-pull/kg), [Shoulder Press](https://strengthlevel.com/strength-standards/shoulder-press), [Machine Shoulder Press](https://strengthlevel.com/strength-standards/machine-shoulder-press). The generically named dumbbell shoulder raise and rear-delt raises were mapped to the loaded dumbbell-raise family.
- Curls and triceps work, ex044, ex047, ex049, ex065, ex073, ex074: [EZ-Bar Curl](https://strengthlevel.com/strength-standards/ez-bar-curl/lb), [Dumbbell Curl](https://strengthlevel.com/strength-standards/dumbbell-curl), [Reverse-Grip Tricep Pushdown](https://strengthlevel.com/strength-standards/reverse-grip-tricep-pushdown/kg), [Machine Tricep Extension](https://strengthlevel.com/strength-standards/machine-tricep-extension/lb), [Lying Tricep Extension](https://strengthlevel.com/strength-standards/lying-tricep-extension/lb), [Reverse Barbell Curl](https://strengthlevel.com/strength-standards/reverse-barbell-curl/lb).
- Bench and incline presses, ex053, ex056, ex057, ex072: [Close-Grip Bench Press](https://strengthlevel.com/strength-standards/close-grip-bench-press), [Incline Bench Press](https://strengthlevel.com/strength-standards/incline-bench-press), [Bench Press](https://strengthlevel.com/strength-standards/bench-press), [Chest Press](https://strengthlevel.com/strength-standards/chest-press). Hammer Strength is a plate-loaded chest-press machine family, so comparisons require the same model and setup.
- Leg extension, hip abduction, kickback, posterior-chain, and calf work, ex059, ex064, ex068, ex069, ex070: [Single-Leg Extension](https://strengthlevel.com/strength-standards/single-leg-extension), [Hip Abduction](https://strengthlevel.com/strength-standards/hip-abduction/kg), [Good Morning](https://strengthlevel.com/strength-standards/good-morning/lb), [Seated Calf Raise](https://strengthlevel.com/strength-standards/seated-calf-raise/lb), [Glute Kickback](https://strengthlevel.com/strength-standards/glute-kickback).

## `NONE` classifications

- ex048, Reverse Lunge: the exact-name [Reverse Lunge standard](https://strengthlevel.com/strength-standards/reverse-lunge) measures bodyweight repetitions, not external load. A separately named barbell reverse lunge is load-based, but that is not this entry.
- ex050, Hanging Knee Raise: inherently bodyweight abdominal repetition work in this entry, with no external-load variant specified.
- ex055, Dip: the JSON explicitly identifies the equipment as `Bodyweight`. Per the project rule, bodyweight dips remain `NONE` even though separately named weighted variants exist.

## Blank classifications

None. Every load-based movement in this range had adequate formula plus named-lift or exercise-family support.

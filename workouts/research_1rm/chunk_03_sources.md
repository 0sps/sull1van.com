# Chunk 03 research: ex075-ex111

## Formula used

All externally loaded resistance exercises in this chunk use the Epley estimate, `w*(1+(r/30))`. Calculator.net describes its one-rep-max calculator as estimating the maximum for a given exercise from weight and repetitions and includes Epley as a selectable formula. The formula reference below gives the exact Epley equation and defines `w` as weight and `r` as repetitions.

- [Calculator.net: One Rep Max Calculator](https://www.calculator.net/one-rep-max-calculator.html)
- [One-repetition maximum formula reference](https://en.wikipedia.org/wiki/One-repetition_maximum)

## Evidence that the named externally loaded movements use 1RM tracking

- `ex075`, `ex079`, `ex083`, `ex084`, `ex086`, `ex088`, `ex100`, `ex104`, `ex111`: Strength Level's exercise index explicitly presents one-rep-max standards and includes Barbell Curl, Seated Shoulder Press, Dumbbell Row, Hip Thrust, Decline Bench Press, Hack Squat, Deadlift, Dumbbell Shrug, and Front Squat. [Strength Level exercise index](https://strengthlevel.com/strength-standards)
- `ex076`: named hip-adduction strength standards explicitly use one-rep max. [Strength Level: Machine Hip Adduction standards](https://strengthlevel.pl/standardy-sily/przywodzenie-nog-na-maszynie/lb)
- `ex077`: named Dumbbell Reverse Fly standards explicitly report values as 1RM. [Fitness Volt: Dumbbell Reverse Fly standards](https://fitnessvolt.com/strength-standards/dumbbell-reverse-fly/)
- `ex085`: the named Incline Dumbbell Squeeze Press page provides a weight and 1RM calculator and identifies it as a bench-press variation. [Fitbod: Incline Dumbbell Squeeze Press](https://fitbod.me/exercises/incline-dumbbell-squeeze-press)
- `ex094`: named weighted/dumbbell step-up standards use estimated 1RM. [Endura: Weighted Step-Ups standards](https://endura.coach/weighted-step-ups-strength-standards-calculator/) and [Endura: Dumbbell Step-Up standards](https://endura.coach/dumbbell-step-up-strength-standards-calculator/)
- `ex101`: named Landmine Press standards explicitly compare one-rep max. [Strength Level: Landmine Press standards](https://strengthlevel.com/strength-standards/landmine-press)
- `ex109`: named Dumbbell Thruster standards direct users to estimate 1RM from a rep set. [Fitness Volt: Dumbbell Thruster standards](https://fitnessvolt.com/strength-standards/dumbbell-thruster/)
- `ex078`, `ex080`, `ex081`, `ex082`, `ex087`, `ex090`-`ex093`, `ex099`, `ex102`, `ex103`, `ex106`-`ex108`: these are externally loaded cable, machine, dumbbell, barbell, or plate movements. The general Epley calculator applies to a given exercise, and Strength Level's indexed standards establish the same 1RM convention across barbell, dumbbell, cable, and machine exercise families. `ex106` Split Squat is treated as loadable rather than inherently bodyweight because loaded split-squat standards explicitly use estimated 1RM. [Bulgarian Split Squat standards](https://endura.coach/bulgarian-split-squat-strength-standards-calculator/)

## `NONE` classifications

- `ex089` Leg Raise, `ex097` Hanging Leg Raise, and `ex110` Reverse Crunch are bodyweight core movements.
- `ex095` Running is cardio.
- `ex096` has the invalid exercise name `0`, so no meaningful 1RM can be defined.
- `ex098` Box Jump is a plyometric performance movement, normally measured by jump height rather than external-load 1RM.
- `ex105` Chest Dip is a bodyweight dip. Per the task rule for bodyweight movements, it remains `NONE` even though weighted dip variants exist.

No candidate was left blank: every movement judged meaningfully loadable had both a general published reps-and-weight Epley equation and online evidence of 1RM use for the named movement or its clearly applicable resistance-exercise family.

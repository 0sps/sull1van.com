# Dashboard Tactile Refinement Design

## Goal

Refine the home dashboard into a warm tactile study console that feels crafted and materially coherent without pushing the quiz experience further.

## Approved Direction

- Use a "refined instrument panel" visual system for the landing page.
- Keep the existing warm parchment palette, but deepen the physical hierarchy through sculpted surfaces, porcelain-like controls, and recessed support modules.
- Limit the stronger neomorphic cues to the dashboard only.

## Visual Hierarchy

1. The hero becomes a master panel.
2. The stat tiles read as precision gauge blocks nested into that panel.
3. The left sidebar reads as recessed supporting modules.
4. Topic cards read as layered study sheets with a clear top plate and quieter subtopic rows.

## Component Treatments

### Hero

- Shift the hero from a soft glass banner to a milled surface with an inner rim, warm highlight wash, and restrained shadow depth.
- Use a more characterful display face for the dashboard headings to add refinement without making the interface decorative.
- Restyle the saved-quiz banner as a tactile status plaque instead of a plain pill strip.

### Stat Tiles

- Treat stat cards like ceramic or enamel gauges set into the hero panel.
- Add shallow inset framing and subtle lower-edge shadows so the numbers feel mounted rather than floating.

### Sidebar Modules

- Convert the dashboard sidebar panels into recessed trays with a light internal bevel.
- Make the recommendation and diagnostic-history cards feel like raised slips placed on those trays.
- Keep copy legible and restrained; the tactile effect should come from surface modeling, not clutter.

### Topic Cards

- Keep each topic card as the main working surface on the page.
- Strengthen the summary header with a softly green instrument-wash and a more deliberate plate treatment.
- Turn subtopic rows into quieter inset slips with clear separation and stronger rhythm.
- Preserve score bars as functional data elements, but give them a machined track feel.

## Interaction Notes

- Dashboard controls should feel pressable, with subtle top highlights and firmer hover depth.
- Avoid rubbery or overly plush shadows; every surface should stay crisp enough for a serious study tool.

## Out of Scope

- Quiz and testing screens
- Topic detail modal redesign beyond inherited shared styles
- Data or interaction model changes
